# Partnership Opportunity: DukeStar - Digital Bridge for Hitster Board Game

**DukeStar** is a cross-platform mobile companion app (Android & iOS) designed to enhance the Hitster music quiz board game experience by seamlessly connecting physical game cards with digital music streaming.

## What DukeStar Does
The app scans QR codes printed on Hitster game cards and instantly opens the corresponding tracks in streaming apps for playback during gameplay. Currently, DukeStar **exclusively supports Deezer** as its music service, using deep links and web integration to provide instant track playback.

## Technical Implementation
- Built with **Kotlin Multiplatform** and **Compose Multiplatform** for native Android & iOS experiences from a single codebase
- Intelligent QR code parsing with direct Deezer integration
- Uses Deezer's web URLs and deep linking for seamless app integration
- Modern architecture with Material 3 design and dependency injection

## Partnership Value
DukeStar represents a unique use case that bridges physical board gaming with digital music streaming, creating:
- **New user touchpoints**: Game night gatherings introducing casual music fans to Deezer
- **Social engagement**: Group settings where music discovery happens organically
- **Extended playtime**: Repeated track playback throughout game sessions
- **Cross-promotion opportunity**: Physical game cards driving digital platform engagement

## Partnership Request
To enhance the user experience and strengthen this integration, we would appreciate:

## Current Status
The app is currently in active development (v1.0) with the **iOS version in beta testing**. DukeStar positions Deezer as the exclusive streaming partner. Future support for additional music services remains currently undecided.
